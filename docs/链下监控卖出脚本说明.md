# 链下监控卖出脚本说明

对应脚本：
- `scripts/testnet/watch-destination-balance-and-sell.js`

这个脚本的作用是：

1. 监控目标链钱包收到的 `OFT`
2. 记录已检测到的到账交易，避免重复处理
3. 读取当前真实池子的储备，估算可换出的 `payoutToken`
4. 按设定滑点计算 `minAmountOut`
5. 自动调用 `swapReceivedOFT(...)`
6. 把“到账 tx -> 卖出 tx”的对应关系写到状态文件

## 这个脚本不是做什么的

- 不是 Solidity 合约
- 不是链上定时器
- 不是自动监听所有地址

它是一个链下 watcher / executor：
- 用你的私钥签名
- 轮询你指定钱包在目标链上的 OFT 余额
- 余额达到阈值后自动卖出

## 必填环境变量

- `WORKFLOW_ADDRESS`
  - 目标链上的 `UnifiedOFTWorkflow` 地址
- `OFT_TOKEN_ADDRESS`
  - 目标链上的 OFT 地址
- `PAYOUT_TOKEN_ADDRESS`
  - 目标链上的目标代币地址
- `FACTORY_ADDRESS`
  - 目标链真实 DEX 的 `UniswapV2Factory` 地址

## 可选环境变量

- `WATCH_ADDRESS`
  - 监控哪个地址的 OFT 余额
  - 默认是当前签名地址

- `RECIPIENT_ADDRESS`
  - 卖出后的 `payoutToken` 发给谁
  - 默认是当前签名地址

- `MIN_WATCH_AMOUNT`
  - 余额达到多少才触发卖出
  - 默认 `1`

- `POLL_INTERVAL_MS`
  - 轮询间隔
  - 默认 `15000`

- `SELL_SLIPPAGE_BPS`
  - 卖出时允许的滑点，单位是 bps
  - 默认 `500`
  - 也就是 5%

- `WATCH_ONCE`
  - 是否只执行一次检查
  - `true` 表示检查一次后退出

- `WATCH_STATE_FILE`
  - 状态文件路径
  - 默认会写到 `scripts/testnet/state/<network>-watcher.json`

- `MAX_SELL_RETRIES`
  - 单笔到账事件最大重试次数
  - 默认 `3`

## 重要限制

`WATCH_ADDRESS` 必须和当前签名地址一致。

原因是：
- `swapReceivedOFT(...)` 会从 `msg.sender` 拉 OFT
- 所以自动卖出的前提是 watcher 自己就拥有那笔 OFT

换句话说：
- 这个脚本适合监控并卖出“当前钱包自己收到的 OFT”
- 不适合监控别人的钱包后代替他们卖出

## 工作流程

1. 轮询新区块
2. 查询 OFT 的 `Transfer` 日志，找出转入 `WATCH_ADDRESS` 的到账交易
3. 把新到账交易加入 `pending`
4. 对 `pending` 里的每一笔：
   - 查当前可卖出的 OFT 余额
   - 从 `factory` 找池子
   - 读池子储备
   - 算预估卖出数量
   - 按滑点折算 `minAmountOut`
   - 调 `swapReceivedOFT(...)`
5. 把到账 tx、卖出 tx、预估输出、实际卖出数量写到状态文件
6. 如果失败，则按 `MAX_SELL_RETRIES` 重试

## 状态文件里有什么

状态文件会记录：

- `lastScannedBlock`
  - 扫描到了哪个区块
- `pending`
  - 当前待处理的到账事件
- `processedIncoming`
  - 已处理完成的到账事件

每条已处理记录里会带：

- `incomingTxHash`
  - 到账交易 hash
- `sellTxHash`
  - 自动卖出交易 hash
- `soldAmount`
  - 本次实际卖出的 OFT 数量
- `expectedOut`
  - 预估可换出的 `payoutToken`
- `minAmountOut`
  - 本次卖出使用的最小接受值

## 最小用法

例如在 Base Sepolia 上运行一次：

```powershell
$env:WORKFLOW_ADDRESS='目标链 workflow 地址'
$env:OFT_TOKEN_ADDRESS='目标链 OFT 地址'
$env:PAYOUT_TOKEN_ADDRESS='目标链 payoutToken 地址'
$env:FACTORY_ADDRESS='目标链 V2 Factory 地址'
$env:WATCH_ONCE='true'
npx hardhat run scripts/testnet/watch-destination-balance-and-sell.js --network base-sepolia
```

## 为什么它满足你的目标

你的目标是：

- 源链真实 swap 后跨链
- 目标链监控到账后卖出

这个脚本就是目标链“监控到账后卖出”的链下执行器。
